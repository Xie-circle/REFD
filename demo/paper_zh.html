广义来源追踪：基于"真实强调与伪造分散"策略检测新型音频深度伪造算法

原文：Generalized Source Tracing: Detecting Novel Audio Deepfake Algorithm with Real Emphasis and Fake Dispersion Strategy
arXiv: 2406.03240v1  ·  中文翻译（核心章节）

摘要

随着深度伪造音频的泛滥，对其来源进行溯源的需求日益迫切。当前的来源追踪方法能够有效区分分布内（ID）类别，但深度伪造算法的快速演进，给准确识别分布外（OOD）的新型深度伪造算法带来了严峻挑战。

本文提出"真实强调与伪造分散"（Real Emphasis and Fake Dispersion, REFD）策略用于音频深度伪造算法识别，证明其既能区分 ID 样本，又能识别 OOD 样本。

为实现有效的 OOD 检测，我们首先探索了现有的后置（post-hoc）OOD 方法，并提出 NSD——一种通过同时考虑特征相似度和 logits 分数来识别新型深度伪造算法的新颖 OOD 方法。

REFD 作为单一系统在 Audio Deepfake Detection Challenge 2023 Track3 中取得 86.83% 的 F1 分数，展现了最先进的性能。

关键词：音频深度伪造算法识别、分布外检测、音频深度伪造检测

1 引言

近年来，文字转语音（TTS）和语音转换（VC）技术（统称"深度伪造音频"）发展迅速。ASVspoof、ADD 等一系列比赛和倡议，推动了针对深度伪造的反制方案研究。目前，在公开数据集上，真假二分类任务的等错误率（EER）已能达到约 0.1%。

然而，只做真假分类并不是终点。执法机构常常需要确定深度伪造音频的来源，以便做出法律裁决；对生成模型的开发者来说，追溯深度伪造音频的来源也关系到算法知识产权的保护。因此，识别音频深度伪造算法意义重大。

音频深度伪造算法识别（ADAR）领域的近期方法，聚焦于分布内（ID）分类。但随着伪造算法的演进，区分新型的分布外（OOD）伪造类别变得越来越关键。为此，ADAR 领域新设了一个挑战赛——ADD2023 Track3。这个任务意义重大：它不仅要检测多种多样的假音频，测试阶段还会出现训练时未知的生成算法，要求检测器既能准确区分 ID 类别，又能识别 OOD 类别。

我们观察到，该赛道上的最优方法，普遍采用多个分类器，用各种特征和骨干网络对"真/假"类别做多分类；测试时再用 OOD 方法检测未知类别，最后融合不同分类器的分数。我们把这类做法称为一阶段（one-stage）方法。

这些一阶段方法存在几个问题：

第一，对一个分类器来说，"区分真假"与"区分不同假类"所关注的特征是不同的，单阶段训练会给分类器带来很大难度。

第二，一阶段方法中，真类也处在 ID 之内，导致 OOD 阈值难以确定。在 ADD2023T3 中，OOD 样本只来自未知的伪造算法。对 ID 里的"真"类而言，OOD 数据是一种语义（真假）偏移；而对 ID 里的"假"类而言，未知假类是一种协变量（假分布内部）偏移。"真"和"假"都在 ID 里，就难以建立一个清晰的判定阈值来检测未知伪造方法。

第三，竞赛里的分数融合，虽然能兼顾不同特征在区分类别时的不同侧重，但往往需要在测试集上反复试验不同的权重来适应，效率低下。

本文提出一种双阶段（dual-stage）的 ADAR 方法，即 REFD 策略：

  • 在真实强调（Real Emphasis）训练阶段，鉴于当前二分类研究的优异表现，我们沿用成熟的二分类策略，并引入 OC-Softmax 来收敛"真"的决策边界。该阶段的首要目标只是检测真类，把假类和未知假类的特征空间留给第二阶段。
  • 在伪造分散（Fake Dispersion）训练阶段，目标是检测未知假类，同时对 ID 假类进行分类。但普通的 softmax 交叉熵，其分类 logits 分数常出现"过自信"问题，这会给区分 ID/OOD 带来困难。为此，我们采用 RegMixup 策略：它继承了 mixup 的强泛化能力，并最大化"熵"的一个软代理，有效解决过自信问题。

为在第二阶段检测未知音频伪造算法，我们研究了 ADAR 领域最先进的、基于分数的 post-hoc OOD 检测器，并进一步提出新的 OOD 检测方法 NSD（Novel Similarity Detection，新颖相似度检测）。NSD 同时考虑特征相似度和分类器 logits，解决了单一视角带来的过自信问题，能在减少远 OOD 区域过自信的同时，实现细粒度检测。

本文主要贡献

  • 提出"真实强调与伪造分散"策略，能有效分类 ID 样本并检测 OOD 样本。
  • 研究了 ADAR 领域最先进的 post-hoc OOD 检测器，并提出 NSD 方法，有效检测未知音频伪造算法。
  • 在 ADD2023T3 上实验评估，单一系统取得 86.83% 的 F1 分数，达到最先进水平。

2 方法

REFD 方法整体流程：

  • 真实强调训练阶段：专注学习真类，利用 OC-Softmax 学习一个紧凑的"真"边界。
  • 伪造分散训练阶段：采用 RegMixup 策略学习"软"logits，解决交叉熵的过自信问题。
  • 推理阶段：先用真实强调预训练模型识别真类，其余音频交给伪造分散模型分类，并用 NSD 检测未知假类。

2.1 骨干网络（Backbone）

W2V2-AASIST 在音频深度伪造检测领域表现最先进。但在训练时对 W2V2 做微调会带来巨大的计算负担（尤其是对后端特征和 logits 施加不同 loss 时）。因此，我们冻结 W2V2 的权重，离线提取 W2V2 的 hidden states 作为特征，输入到后端 AASIST，从而便于用各种 loss 进行训练。

2.2 真实强调训练阶段（RE）

该阶段所有训练音频都参与训练：真音频标为 0，假音频标为 1，采用二分类 logits 输出（真/假）。

利用 OC-Softmax 学习一个单类紧凑的真实决策边界。真实强调阶段的损失 L_RE 定义为：

L_RE = (1/N) · Σᵢ log( 1 + e^( α·(m_yᵢ − ŵ₀·x̂ᵢ)·(−1)^yᵢ ) )

其中，xᵢ ∈ R^D，yᵢ ∈ {0,1}，w₀ 表示目标类的嵌入方向。AASIST 输出的特征 x 与权重向量 w₀ 归一化后，计算特征与目标方向的余弦相似度。然后用两个 margin（m₀、m₁）约束 x 与 w₀ 之间的夹角 θᵢ：

  • 当 yᵢ=0（真）时，用 m₀ 保证 θᵢ 更小——即"真"样本离目标方向更近；
  • 当 yᵢ=1（假）时，用 m₁ 保证 θᵢ 更大——即"假"样本离目标方向更远。

推理阶段，就用 x 与 w₀ 的夹角相似度来判断音频是真还是假。

2.3 伪造分散训练阶段（FD）

Mixup 策略基于邻近风险最小化（VRM），在 ID 分布附近合成新样本，丰富 ID 数据分布，使 ID 与 OOD 样本之间产生角度偏差。但单独使用 Mixup，往往交叉验证效果有限且行为高熵。于是采用 RegMixup——它同时结合了经验风险最小化（ERM）和 VRM。FD 阶段的损失 L_FD 定义为：

L_FD = CE( pθ(ŷ | xᵢ), yᵢ ) + η · CE( pθ(ŷ | x̄ᵢ), ȳᵢ )

其中，对 batch 中的每个样本 xᵢ，随机从同一 batch 中选另一个样本 xⱼ，得到插值后的 x̄ᵢ 和 ȳᵢ；CE 表示标准交叉熵损失。

2.4 推理阶段（Inference）

推理阶段提出新 OOD 检测器 NSD。

设 X_m = (x₁, …, x_m) 表示全部 m 个训练样本，Y_n = (y₁, …, y_n) 表示测试样本。用预训练的伪造分散模型 φ，得到训练特征 Z_m 与测试特征 T_n，以及它们的 logits L_m、L_n。

NSD 把整个训练域的特征当作一个已知类，逐对计算测试域与训练域特征之间的余弦相似度，得到 n×m 维相似度矩阵 S_NSD。然而，相似度计算中的归一化会消除数值的尺度信息，导致细粒度检测受限。于是，用分类 logits 在细粒度数值层面去缩放相似度矩阵。NSD 分数计算如下：

S_NSD = ( T_n · Energy(L_n) ) · ( Z_m · Energy(L_m) )

其中，Energy 是一种置信度缩放分数，用于平滑原始 logits、增强泛化性。沿 m 维求平均，得到 n 个测试样本的分数矩阵。分数小于阈值的样本，被识别为新型伪造算法。

  • 训练集：22,397 条音频，含真（class 0）和 6 种生成方法（class 1–6）。
  • 开发集：8,400 条音频，同样含真和 6 种生成方法（class 1–6）。
