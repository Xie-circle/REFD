## 一、今天读懂了什么（用自己的话）

### 1. 为什么非要分两个阶段（RE + FD）

- 老办法（一阶段）想"画一条线"把真假分开，但**画线得先知道假有哪些**；
- 我们这个任务恰恰是**要抓没见过的新假** → 假有哪些永远画不全 → 画线不现实；
- 所以改成：**RE 立一个"真实中心"，只认准"真"，其余（所有假+新假）打包丢给 FD**；
- **FD 再从假里把"没见过的"捞出来**。

一句话：**RE 管真假（像不像真的），FD 管新旧（是不是没见过的）。**

### 2. RE 阶段（2.2）：立中心，不画线

- 标签：真 = 0，假 = 1（所有假都归 1，dataset.py 里的 `{"0":0,"1":1,...}`）。
- **OC-Softmax** 的核心：学一个"真实中心" **prototype**（论文里叫 w₀）。
- 训练：把"真"往中心**拉近**，把"假"往外**推开**。
- 推理：新音频的特征和 prototype 算**余弦相似度**（点积），>0 判假、<0 判真。
- 代码对应：
  - `model.py` — `loss, prototype = self.ocsoftmax(last_hidden, label)`（训练时学出中心）
  - `generate_score_da.py` — `feats @ prototype` 算相似度，再判真/假

### 3. FD 阶段（2.3）：多分类 + 治"过自信"

- 任务变了：**8 分类**（真 0 + 假1~假7）。
- **病根 = 过自信**：普通训练只见过"硬标签"（每个样本 100% 是某类），
  于是遇到没见过的新假，也会硬装认识、打一个高分 → 分不出 ID/OOD。
- **药方 = mixup**：把两条已知样本按比例"兑"成一个**四不像**（特征和标签都兑），
  逼模型学会"遇到模棱两可 → 输出软软的、低而模糊的分数"。
- **RegMixup = 正常训练(ERM) + mixup 训练(VRM)** 两条腿一起走。
- 代码对应：`main_train.py` 里的 `mixup_data`（兑）+ `regmix_criterion`（照软标签算 loss）。

> ⚠️ 易错点：mixup 训练的是 **FD 多分类模型**，不是 OOD 检测器；
> OOD 检测器（NSD）是后面**借用** FD 模型吐出的特征和 logits，自己不训练。

### 4. 推理阶段（2.4）：NSD 两个依据

FD 模型对每段音频吐两样东西：**feats**（特征向量）+ **logits**（8 个分类分数）。

- **特征相似度** = 看"方向"（像不像）—— 拿 feats 和训练集挨个比余弦相似度；
- **logits 分数** = 看"尺度"（多强烈 / 多确信）—— 模型自己的判断底气。
- **两个都要，因为互补**：
  - 只看 logits → 会被"过自信"骗（新型也打高分）；
  - 只看相似度 → 余弦归一化丢了"尺度"，不够精细。
- 两个分数**乘一起**：**分数低 = 像没见过的陌生人 = 新型（class7）**。
- 代码对应：`ood_detector.py`（setup 存训练集特征/logits，infer 算 NSD 分数，低于阈值标 class7）。

### 5. 顺带彻底搞懂的训练循环（复习强化）

```
做题(前向) → 打分(loss) → 找错因(backward) → 改参数(optimizer) → 再做题 → …
```

- **损失函数**只负责"打分"（差多少）；**反向传播**算"每个参数该往哪调"；
- 真正动手改参数的是**优化器 optimizer**（`main_train.py` 里 `feat_optimizer.step()`）。
