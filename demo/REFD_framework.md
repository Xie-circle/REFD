# REFD 项目学习框架图（第 2 周）

## 一、项目在做什么（一句话）
检测音频真假，并能识破"没见过的新型伪造算法"。

## 二、核心分工
| 阶段 | 管什么 | 类比 |
|------|--------|------|
| RE  | 真假 | 是不是"猫科动物" |
| FD  | 新旧 | 是"猫/狗"，还是"没见过的兔子" |

## 三、完整流程

```
一段音频
  │
  ├─ RE 阶段（管真假）
  │   ① 特征提取：wav2vec2（借用的预训练模型）→ 特征矩阵
  │   ② 训练：二分类模型 W2VAASIST（真 / 假）
  │   ③ 打分：RE 分数 = 离"真实中心(prototype)"多远
  │
  └─ FD 阶段（管新旧）
      ① 训练：多分类模型（真 / 假1 / 假2 / ... / 假7）
      ② OOD 预处理：模型吐出 feats(浓缩向量) + logits(分类分数) → 存成文件
      ③ OOD 打分：判断"是不是没见过的新型"
      ④ 融合 RE + FD → 最终判断 → 算 F1
```

## 四、必须记住的概念

1. **特征**：把音频变成数字矩阵（wav2vec2 做的）；模型再把它"消化"成浓缩向量
2. **训练循环**：反复「做题 → 对答案(loss) → 自动改参数」
3. **prototype（真实中心）**：训练时学到的"真实语音的位置"，用来算 RE 分数
4. **OOD（分布外）**：没见过的新型伪造，类比"猫/狗 vs 兔子"
5. **二分类 vs 多分类**：RE 分"真/假"；FD 分"真 + 7 种伪造"
6. **训练 = 学规则，不是背答案**（这叫"泛化"）
